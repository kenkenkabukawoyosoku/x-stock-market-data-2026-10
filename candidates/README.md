# Candidate Lists for Prediction Accuracy Tracking

このフォルダには、**予想精度を今後検証するための候補ユーザーリスト**が入っています。

## ファイル

- `jp_candidates.json` … 日本株関連の候補アカウント（約50人）
- `us_candidates.json` … 米国株関連の候補アカウント（約50人）

## 注意

- **これは精度ランキングではありません。** これから検証するための初期リストです。
- **選定基準（2026-10-13 決定）**: フォロワー **300 以上**、アカウント作成から 180日以上、直近90日で銘柄に触れた投稿が月4件以上、重複アカウントでない、ニュース転載・まとめ・企業アカウントでない。
- 外した候補も削除せず `status: "removed"` と `removed_reason` で残しています。
- 収集日時: 2026-10-13

## 次のステップ案

1. 各候補の最近の投稿を定期収集
2. 「銘柄 + 方向 + 期間」が明確な予想を抽出
3. 一定期間後に実際の値動きと比較しスコアリング
4. サンプル数が十分な人からランキング化
