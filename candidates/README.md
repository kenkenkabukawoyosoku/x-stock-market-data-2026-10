# Candidate Lists for Prediction Accuracy Tracking

このフォルダには、**予想精度を今後検証するための候補ユーザーリスト**が入っています。

## ファイル

- `jp_candidates.json` … 日本株関連の候補アカウント（約50人）
- `us_candidates.json` … 米国株関連の候補アカウント（約50人）

## 注意

- **これは精度ランキングではありません。** これから検証するための初期リストです。
- **選定基準（2026-10-13 決定）**: フォロワー **300 以上**、アカウント作成から 180日以上、直近90日で銘柄に触れた投稿が月4件以上、重複アカウントでない、ニュース転載・まとめ・企業アカウントでない。
- 外した候補も削除せず `status: "removed"` と `removed_reason` で残しています。
- **毎日の収集対象（2026-10-19〜）**: `status: "active"` かつ `collect_daily: true` の人だけ（JP 8件・US 6件）。Grok が1回に回れる件数（JP 5〜10件、US 6件前後）に合わせ、少ない人数を毎日もれなく取るために絞った。
  - 選び方は、予想を「銘柄＋方向＋期間か目標」の形で書くか（これまでの投稿の形式）と、`added_reason: reputation` の人（前向き評価のため）。**当たったかどうかでは選んでいない。** 理由は各候補の `collect_daily_reason`。
  - 評価は `collect_daily` が true になった日（2026-10-19）以降に収集した投稿で行う。それより前は収集が不完全な日がある（10/16〜10/18 に欠測あり。CHANGELOG 参照）。
  - `collect_daily: false` の人も候補リストには残す。収集を増やせるようになったら戻す。
- 収集日時: 2026-10-13

## 次のステップ案

1. 各候補の最近の投稿を定期収集
2. 「銘柄 + 方向 + 期間」が明確な予想を抽出
3. 一定期間後に実際の値動きと比較しスコアリング
4. サンプル数が十分な人からランキング化
