## 候補ユーザーリストについて

`candidates/` フォルダには、定期的に銘柄や投資見解を発信しているアカウントの初期リストを入れています。

- **精度ランキングではありません**（これから検証するための候補）
- フォロワー数が極端に少ないアカウントは除外
- 今後の流れ案：投稿収集 → 予想抽出 → 事後検証 → スコアリング
