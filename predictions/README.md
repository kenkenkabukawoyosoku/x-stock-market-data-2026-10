# Predictions Tracking

候補ユーザーの投稿から「検証可能な予想」を抽出し、後で精度を測るためのフォルダです。

## ファイル

| ファイル | 内容 |
|---------|------|
| `schema.md` | 抽出ルールとJSONスキーマ |
| `samples_2026-10-12.json` | 初期サンプル予想（未評価） |

## 運用フロー

1. **収集** … 候補ユーザーの最新投稿を取得
2. **抽出** … schemaに従って「銘柄+方向+期間」が明確な予想だけ記録
3. **保存** … `predictions/YYYY-MM-DD.json` などに追記
4. **評価** … 期間経過後に実際の値動きと比較し `status` を更新
5. **集計** … ユーザー別に的中率・サンプル数を計算

## 注意

- 投資助言ではありません
- サンプル数が少ない段階ではランキング化しない
- 曖昧な投稿は無理に抽出しない
