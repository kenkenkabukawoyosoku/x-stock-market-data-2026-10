# logs/grok/ — Grok の作業記録

Grok が実行ごとに**新しいファイルを1つ**作る場所です（2026-10-17〜）。既存のファイルは変更しません。
Claude は毎回、前回より後に増えたファイルを読みます。

- ファイル名: `YYYY-MM-DD_HHMM_{jp|us|task}.md`（実行日と開始時刻は JST。`jp` = 08:00、`us` = 22:00 の Automation、`task` = それ以外）
- 同じ名前があれば上書きしない（時刻を変えるか `_2` を付ける）。

## 中身

```markdown
# YYYY-MM-DD HH:MM JST — Grok — daily-{jp|us}
- 作ったファイル: <パスと行数>
- 収集: <対象アカウント数> 件中 <取得できたアカウント数> 件、投稿 <数> 件
- 取得できなかったアカウント: <名前をすべて。なければ「なし」>
- 削除検知: <件数>
- 対応した §6 の依頼: <G番号と結果。なければ「なし」>
- → Claude: <伝えたいこと。なければ「なし」>
```
