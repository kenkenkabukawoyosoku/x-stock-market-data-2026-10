# ランキング公開時の注意書き（P1-6）

公開物（README、レポート、ランキング表）に載せる文言と、使ってはいけない表現。

---

## 1. 掲載用の注意書き（そのまま使える文面）

### 短縮版（表やグラフの直下に）

> 本表は X 上の公開投稿を事後に集計したもので、投資助言ではありません。過去の的中率は将来の成績を保証しません。数値には統計的なばらつきがあり、件数の少ない順位は偶然で入れ替わります。

### 全文版（レポート冒頭・README に）

> **ご注意**
>
> 1. 本資料は、X（旧Twitter）で公開された投稿に含まれる株価の見通しを、定めた基準で事後に集計した研究目的の記録です。特定の銘柄の売買を勧めるものではなく、金融商品取引法上の投資助言・代理業にあたる行為を意図したものではありません。
> 2. 掲載したアカウントや投稿を推奨・保証するものではありません。掲載アカウントへの有料サービス・グループ等への勧誘とは無関係です。
> 3. 的中率・スコアは、限られた件数と期間にもとづく推定値です。表示する区間（信頼区間・事後区間）は、実際の値がその範囲のどこにあってもおかしくないことを示します。
> 4. 多数のアカウントを比べると、実力に差がなくても偶然で上位が生じます。上位であることは、将来も上位であることを意味しません。
> 5. 投稿の削除・編集・収集漏れにより、集計に含まれない予想があります。
> 6. 判定基準（エントリー価格、期間、ベンチマーク）は `review/evaluation_rules.md` に公開しています。基準が異なれば結果も変わります。
> 7. 投資判断はご自身の責任で行ってください。

## 2. 使ってはいけない表現 → 言い換え

| 避ける | 理由 | 言い換え |
|---|---|---|
| 「当たる人」「最強」「神」 | 断定。サンプルが少ない段階では統計的に言えない | 「集計期間中のスコア上位」 |
| 「この人をフォローすれば勝てる」 | 将来の成績の保証・助言 | 使わない |
| 「的中率80%」（件数・区間なし） | 誤解を招く | 「80%（12件中、95%区間 52〜93%）」 |
| 「〇〇氏の推奨銘柄 一覧」 | 推奨の再配布になり、助言と受け取られうる | 銘柄名ではなく集計値だけを出す。個別の予想は投稿 URL へのリンクにとどめる |
| 「損益 +○○万円」 | 個人の損益の断定（HANDOFF §10） | 「超過リターンの平均（ボラティリティ調整後）」 |
| 「外れ続けている人」「ワースト」 | 特定個人への否定的な評価。トラブルの原因になる | 下位は公開せず、上位と「参考」区分のみ載せる |

---

## 3. 公開範囲について

- **下位ランキングは公開しない。** 個人への否定的評価の公開は、名誉毀損等のトラブルにつながりうる。内部分析にとどめる。
- 本文の転載は最小限にし、**投稿 URL へのリンク**で示す（X 利用規約・著作権。HANDOFF §10）。
- 本人から掲載停止の申し出があった場合の窓口（Issue など）を README に書いておく。
- 「投資顧問」等を名乗るアカウントを掲載する場合、登録の有無を確認できないなら掲載しない。
