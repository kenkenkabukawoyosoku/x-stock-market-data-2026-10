# スコアリング式 提案（P0-2）

前提: 個々の予想は `evaluation_rules.md` で `hit / miss / flat / void` と超過リターンの z スコアまで評価済みとする。
このファイルは、それを**ユーザー単位の順位付け**にまとめる方法を決める。

---

## 1. 結論（採用案）

ユーザーごとに次の2つを出し、**主指標は Skill Score** とする。

| 指標 | 何を測るか | 式 |
|---|---|---|
| **Skill Score（主）** | 予想の方向にどれだけ、ボラティリティの割に超過リターンが出たか | 縮小推定した加重平均 z（§3） |
| **的中率（副）** | 当たった割合 | ベイズ縮小した的中率 + 95%区間（§4） |

現行案（方向一致 +1 / 目標到達 +1 / 大外れ 0 or −0.5）は採用しない。理由:

- **市場ベータが残る**: 上昇相場で全部 long にすると +1 が並ぶ。
- **時間軸とボラティリティが無視される**: 小型株の1週間+5% と大型株の3ヶ月+5% が同じ点数になる。
- **目標到達 +1 は大きい目標を出すほど得**ではなく、むしろ控えめな目標ほど得になり、「予想価格：4桁」のような誇大目標を罰しない。進捗率で連続的に評価する方がよい。
- **−0.5 の根拠がない**: どの程度の外れを「大きく」とするか決まっていない。

---

## 2. 予想ごとの重み

```
w_i = w_type × w_post × w_horizon
```

| 要素 | 値 | 理由 |
|---|---|---|
| `w_type` | long/short = 1.0、avoid = 0.5、conditional = 1.0 | avoid は主張が弱い |
| `w_post` | 1 / `post_ticker_count` | 「今週上がる10銘柄」を1投稿で出すと10件分の重みになるのを防ぐ。1投稿＝1意見 |
| `w_horizon` | `horizon_source` が `explicit` = 1.0、`inferred` = 0.7、`default`（`target_only` と期間なしの avoid）= 0.5 | 期間を自分で明示した予想を優先 |

**実効サンプル数**: `n_eff = (Σw)² / Σw²`。ランキングの掲載条件は件数ではなくこの値で判定する。

---

## 3. Skill Score（主指標）

各予想の `z_i = clip(dir × r_ex / σ_h, −3, 3)`（`evaluation_rules.md` §3）。

```
raw_i   = z_i + 0.5 × target_bonus_i
target_bonus_i = progress_i（目標株価つきのみ、[−1, 1]。目標なしは 0）

mean_w  = Σ(w_i × raw_i) / Σw_i
Skill   = mean_w × n_eff / (n_eff + k)      # k = 20（縮小定数）
SE      = std_w(raw) / √n_eff
```

- **縮小（shrinkage）**: 件数が少ない人ほど0に引き戻す。n_eff = 20 なら平均の半分、n_eff = 60 なら 3/4 が残る。
- 0 = ランダムに銘柄を選んだのと区別できない水準。+0.2 以上が数十件続けば、明確な腕がある部類。
- `z` を ±3 でクリップするのは、1件の大当たり（ストップ高連発など）で順位が決まらないようにするため。
- **目標ボーナスの係数 0.5** は、方向の当たりより目標の精度を軽く見る設計。誇大目標（progress がほぼ 0 か負）は自動的に伸びない。

---

## 4. 的中率（副指標）

`flat` と `void` は分母から除く。重みつきで計算する。

```
H = Σ w_i [hit],  M = Σ w_i [miss]
事後分布: Beta(H + 5, M + 5)      # 事前 Beta(5,5) = 「50%前後」を仮定
表示値   = 事後平均 (H+5)/(H+M+10)
区間     = 事後分布の 2.5%〜97.5% 点
```

- 表示するときは**必ず区間を併記**する（「62%（95%区間 48〜75%）」）。
- 「的中率の基準値」は 50% ではなく、**同じ銘柄・期間で常に long だった場合の的中率**（ベースライン）と比べる。超過リターンで判定していれば理論上ほぼ 50% だが、ベンチマークの選び方次第でずれるので毎月実測する。

## 5. サンプル数とランキング掲載条件

### 5.1 件数の目安（実際に計算した値）

的中率 60% の人と 50%（コイン投げ）の人を区別するのに必要な件数:

| 真の的中率 | 必要な独立予想数（片側5%、検出力80%） |
|---|---|
| 55% | 約 620 件 |
| 60% | 約 150 件 |
| 65% | 約 70 件 |

観測された的中率 60% の 95% 信頼区間（Wilson）:

| n | 区間 |
|---|---|
| 20 | 39%〜78% |
| 50 | 46%〜72% |
| 100 | 50%〜69% |

**多重比較の罠**: 実力ゼロ（50%）のアカウントが100人いると、各30件の時点で**最上位の的中率は中央値で約73%**になる（シミュレーション、2000回）。100人規模で「上位5人」を並べると、腕がなくても見栄えのよい数字が出る。

### 5.2 掲載ルール

| 区分 | 条件 | 表示 |
|---|---|---|
| 非表示 | `n_eff < 10` | 載せない |
| 参考 | `10 ≤ n_eff < 30`、または評価期間がのべ2ヶ月未満 | 指標と区間だけ載せ、順位はつけない |
| ランキング | `n_eff ≥ 30` かつ 2ヶ月以上の異なる月にまたがり、10銘柄以上 | 順位をつけるが区間を必ず併記 |
| 確度あり | `n_eff ≥ 100` かつ §6 のアウトオブサンプル検証を通過 | 「継続して上位」と書いてよい |

## 6. アウトオブサンプル検証（実力か運かの確認）

1. 評価済みの予想を時系列で前半・後半に分ける。
2. 前半の Skill で上位 20% に入った人の、後半の Skill の平均を見る。
3. 後半でも 0 より有意に大きければ「持続性あり」。0 に戻るなら前半の上位は運だった可能性が高い。

これを四半期ごとに行い、レポートに載せる。**持続性が確認できるまでは「当たる人」という言い方をしない。**

---

## 7. 補助的に出す指標（ランキングには使わない）

| 指標 | 用途 |
|---|---|
| long 比率 | 常に買い推奨の人を可視化（ベータ依存の目安） |
| 平均保有期間 | 短期勢と長期勢を分けて比べるため |
| 目標の誇大度 `median((target − P_t0) / σ_h)` | 「予想価格：4桁」型の誇大目標を見つける |
| キャリブレーション | 自信の強さ（`strength`）別の的中率。「強気」と言ったときほど当たっているか |
| 最大逆行幅（MAE）の中央値 | 当たった予想でも途中でどれだけ逆行したか（実際に従えたか） |

## 8. 計算例

ある作者の予想3件（すべて1投稿1銘柄、期間明示、w=1）:

| 予想 | dir | r_ex | σ_h | z | progress | raw |
|---|---|---|---|---|---|---|
| A long | +1 | +4.0% | 5.0% | +0.80 | — | +0.80 |
| B long（目標+9%） | +1 | +3.0% | 6.0% | +0.50 | +0.33 | +0.67 |
| C short | −1 | +2.0% | 4.0% | −0.50 | — | −0.50 |

`mean_w = 0.32`、`n_eff = 3` → `Skill = 0.32 × 3 / 23 = 0.04`（ほぼ 0 に縮小。3件では何も言えない）。
